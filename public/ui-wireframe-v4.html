Visual Rules

強い背景面は「判断」か「入力」だけ。情報確認は薄い背景と罫線で済ませ、面を増やさない。

  • 数字はカードで囲わず、上端ルール付きの KPI strip で扱う
  • イベント一覧は list row 化して、1件ごとの箱を作らない
  • 操作フォームだけを 1 つの strong surface に寄せる

Simulation Workspace

左は残高の判断、下は根拠イベント。チャートと一覧を同じ文法で扱い、どちらも「箱の中の箱」にならないようにしています。

Component Direction

  1. `surface-strong`: composer, confirm, alert だけに使う
  2. `surface-soft`: chart shell や grouped section にだけ使う
  3. `row-item`: ledger, events, account list の標準形にする
  4. `pill`: filter と state のみ。説明文の代替として多用しない
